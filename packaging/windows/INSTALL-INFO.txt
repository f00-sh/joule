joule — Windows installer
=========================

This Setup wizard installs the real joule program:

  • joule.exe — native GUI dashboard (default) + full CLI
  • Start Menu shortcut
  • Optional desktop icon
  • Optional user PATH entry for terminals

After install:
  1. Launch "joule" from the Start Menu (opens the interactive dashboard)
  2. Click "Start control" then "Start agent (donate)"
  3. Or in a terminal:  joule version

Unsigned builds: Windows SmartScreen may warn until Authenticode
code-signing is available. Choose "More info" → "Run anyway".
