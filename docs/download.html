After install (do not skip)

  1. Launch joule (GUI is the default when you type joule).
  2. Click the big green ★ DO EVERYTHING (local pool) button (starts control + agent). Or run joule start in a terminal.
  3. Wait ~10 seconds for challenges. Status should show a connected pool.
  4. Open the Chat tab, or: joule connect then joule chat --prompt hi.
  5. Survive reboot: joule service install (writes + enables control + agent + tray for your OS user session).
  6. Back up your CODE / JOULE-RECOVERY.txt.
  7. Stuck? joule get-started prints the full dumb-user checklist.

Honest product bar:

  • Not every client downloads full multi‑TB weights — donors hold band/shard slices; weights are peer-seeded by sha256 (f00 is website only).
  • Full Kimi fleet gate: ≥3 healthy backends and ≥64 GiB aggregate VRAM, plus digests matching production kimi-k3-shards (96 real Moonshot pins).
  • One PC still runs a real local pool (lab / first-light) on the production engine path; lab fixtures are not full Kimi quality.
  • Contribute-to-consume: freeloaders without a healthy agent get no chat API.
