After install

  1. Install (above) — then just run the agent. Done.
  2. joule agent --control HOST:7701 — auto CODE (secret UUID) + signed account the pool accepts.
  3. Other PCs: joule identity use YOUR-CODE — same millijoules (code derives the key; signatures prove it).
  4. See code again: joule identity show — never share CODE publicly.
