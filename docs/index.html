How it works

  1. Install the native joule agent on a machine you control (not the browser).
  2. It joins the internet-wide cluster and donates VRAM to one logical device.
  3. You earn millijoules for heartbeats, honest challenges, and real shards.
  4. Point any OpenAI-compatible client at the gateway with your key and spend mJ.
  5. When the pool crosses milestones (VRAM + backends), we load open Kimi weights and go live.

Millijoules, explained

A millijoule (mJ) is an integer credit on the ledger. 1000 mJ = 1 J (display only). You cannot buy them with money on the public pool.

You doLedger
Healthy heartbeatMint (small base × fairness factors)
Serve an inference shardMint (tokens × factors)
Pass a spot challengeMint (anti-cheat honesty)
Call chat / completionsBurn (prompt + 4× completion tokens × leecher factor)

Every ledger line embeds eco=v0 and the basis-point factors so you can recompute the total. Spec: economy-v0.md.

Fairness algorithm (auditable)

√VRAM, not aristocracy

1 GiB ≈ 1×, 4 GiB ≈ 2×, 16 GiB ≈ 4×, cap 8×. Linear VRAM would freeze out laptops.

Tenure boost

Continuous healthy time multiplies mint up to 1.5×. Offline resets the streak. Loyalty pays.

Leecher penalty

If consume ≫ contribute in the window: earn down to 0.25×, pay up to 4×. Pure freeloaders get crushed.

Open constants

Pure Rust, integer math, unit tests. No hidden admin multipliers in the public scoring path.

mint = base × mem_bp × tenure_bp × leecher_mint_bp
burn = (prompt + 4×completion) × leecher_usage_bp
# bp in 1/10000 units · eco=v0
